Task manager with some features 

Таск менеджер для управления задачами, позволяет создавать, редактировать, удалять, отслеживать общий прогресс. 

Стек? react typescript vite css react hooks lucidereact 

Хранение через localstorage

архитектура по компонентному принципу, разделение состояний, ui, data

Установка и запуска (node.js and npm required)
Клонируете репозиторий или скачиваете архив и устанавливаете в удобное место 

Установка зависимостей

npm install

Запуск проекта в режиме разработки

npm run dev

После запуска Vite выведет локальный адрес приложения в терминале.

Ориентировочное время выполнения ~3 часа
